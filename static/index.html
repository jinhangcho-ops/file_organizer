    이 PC는 파일을 연 시각을 기록하지 않습니다. 그래서 '안 본 파일'은 수정한 시각으로 판단합니다. 기록을 켜려면 관리자 권한 PowerShell에서 fsutil behavior set disablelastaccess 0을 실행한 뒤 다시 시작하세요.
