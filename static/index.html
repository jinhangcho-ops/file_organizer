내용 미리보기

이 PC는 파일을 연 시각을 기록하지 않아요. 그래서 “안 본 파일”은 수정한 시각으로 판단해요. 기록을 켜려면 관리자 권한 PowerShell에서 fsutil behavior set disablelastaccess 0을 실행한 뒤 다시 시작하세요.

색인할 폴더

놓을 곳은 따로 넣지 않아도 색인해요. Windows, Program Files, AppData, 숨김·시스템 폴더는 들어가지 않아요.

색인 단계

파일 목록을 훑은 다음 위에서부터 차례로 해요. 끈 단계는 [색인 갱신]에서 빠지고 [이것만 하기]로만 돌아요.
동영상 장면 간격 초 · 같다고 볼 유사도 %

기간

목록 위쪽 버튼이 이 기준으로 파일을 골라요.
최근 다운로드·최근 수정은 최근 일
안 본 파일은 일 넘게

예외

여기 추가한 파일은 위 네 목록에서 빠져요.
예외로 지정한 파일이 없어요.
목록에서 파일을 오른쪽 클릭하고 “예외로 지정”을 고르세요.

차단 폴더

색인하지 않고, 목록·검색·정리·옮기기·휴지통·보관 어디서도 다루지 않아요. 시스템·게임 폴더처럼 건드리면 안 되는 곳을 넣으세요. 추가하면 그 아래의 색인 기록을 바로 지워요(실제 파일은 그대로).
관리자 권한으로 실행하면 바꿀 수 있어요. 지금은 보기만 돼요.
차단한 폴더가 없어요.

구조 보호 폴더

작업 폴더처럼 안의 구조를 바꾸면 안 되는 폴더예요. 목록·검색에는 그대로 나오지만, 폴더 자신을 옮기거나 이름을 바꾸거나 지울 수 없고, 안의 파일·폴더도 이름 바꾸기·휴지통·오래된 파일 보관을 하지 않아요. 안의 것을 밖으로 옮기거나 안으로 넣는 것은 돼요.
관리자 권한으로 실행하면 바꿀 수 있어요. 지금은 보기만 돼요.
구조 보호 폴더가 없어요.

잠금 폴더

비밀번호를 넣어야 열리는 폴더예요. 왼쪽 폴더 목록에서 폴더를 오른쪽 클릭하고 “잠그기”를 고르세요. 잠그면 Windows 권한으로 내 계정의 접근을 막고 숨겨요. 암호화는 아니어서 관리자나 권한 명령을 아는 사람은 풀 수 있어요(가리기 수준). 열어 둔 폴더는 프로그램을 닫을 때 다시 잠가요.
“금고로 모으기”를 고르면 폴더를 금고 안으로 옮겨(무작위 이름) 금고 하나만 잠가요. 원래 위치는 암호화한 비밀 파일에만 남고, [꺼내기]로 되돌려요. 금고와 같은 디스크의 폴더만 모을 수 있어요.
잠근 폴더가 없어요.

다운로드 정리하기

고른 곳 바로 아래의 파일만 종류별 폴더로 옮겨요. 하위 폴더와 그 안의 파일은 그대로 둬요.

정리할 곳

놓을 곳

이 폴더 안에 문서, 발표 자료, 표, PDF, 사진, 이미지 … 폴더를 만들어 옮겨요. 같은 이름이 있으면 ‘이름 (2)’로 저장해요.

파일종류옮길 곳

오래된 파일 보관

오래 열지도 수정하지도 않은 파일을 보관할 곳의 zip 하나로 묶고, zip을 확인한 뒤 원본은 휴지통으로 보내요.

보관할 곳

예: D:\Archive_ColdStorage. zip 안에는 원래 경로(C\Users\…)가 그대로 들어가요.

기간

일 넘게 안 본 파일
설치파일(exe 등), 예외로 지정한 곳, 휴지통으로 보낼 수 없는 곳(네트워크·이동식 디스크)의 파일은 넣지 않아요. 압축·동영상·음악·사진처럼 이미 압축된 파일은 다시 압축하지 않고 그대로 넣어요.
