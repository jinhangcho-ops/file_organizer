# 파일 정리

다운로드한 파일을 종류별 폴더로 정리하고, 이름·종류·날짜·크기·파일 안의 글자로 찾는 Windows 프로그램입니다. 중복 의심, 최근 다운로드·수정, 오래 안 본 파일을 모아 보고, 여러 파일을 끌어 놓아 옮기거나 휴지통으로 보낼 수 있습니다. 1년 넘게 안 본 파일은 다른 드라이브의 zip으로 보관할 수 있습니다.

## 실행

`dist\file_organizer\file_organizer.exe`를 실행합니다.

소스에서 실행하려면:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python desktop.py
```

exe 만들기:

```bash
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller file_organizer.spec
```

처음 쓸 때는 설정(톱니)에서 색인할 폴더를 확인하고 [색인 갱신]을 누릅니다. 목록, 검색, 중복 의심 등의 목록은 모두 색인을 읽습니다.

## 화면

- **제목 줄:** 프로그램이 직접 그립니다. 끌면 창이 움직이고, 두 번 누르면 최대화·되돌리기입니다. 오른쪽 버튼은 화면 색 바꾸기(라이트·다크, 기억함. 처음에는 Windows 설정을 따름), 최소화, 최대화, 닫기입니다. 창 가장자리를 끌면 크기가 바뀝니다.
- **도구 줄:** 검색창(파일 이름이나 폴더 이름), [조건], 필터 칩(중복 의심·최근 다운로드·최근 수정·N일 넘게 안 본 파일), 아이콘(다운로드 정리하기, 오래된 파일 보관, 휴지통, 설정). 설정 등 다른 화면에서는 ←로 목록에 돌아옵니다.
- **왼쪽 폴더 목록:** 맨 위의 '모든 파일'과 색인한 폴더들. 형제끼리는 파일이 많은 폴더부터 놓이고, 막대와 숫자는 그 아래 전체의 파일 수입니다. 폴더를 누르면 그 폴더(하위 포함)의 파일이 가운데에 나오고 펼쳐집니다. ▸/▾는 펼치기·접기만 합니다. 아래에 색인 진행 상황이 나옵니다.
- **가운데:** 폴더 이름과 경로, 종류 칩(문서, 발표 자료, 표, PDF, 사진, 이미지, 동영상, 음악, 압축, 설치파일, 기타), 종류를 고르면 그 안의 확장자 칩(예: 문서 → docx, hwp, md, txt), 파일 표(체크 칸, 이름, 크기, 날짜). 표의 머리글을 누르면 정렬됩니다. 크기는 Windows 탐색기처럼 바이트·KB·MB·GB로 보입니다(예: 88.0 KB, 1.20 MB). 날짜 열은 필터에 따라 받은 날짜(최근 다운로드), 마지막으로 연 날짜(안 본 파일), 그 밖에는 수정한 날짜입니다. 아래 상태 줄에 고른 개수가 나옵니다.
- **오른쪽 상세:** 파일을 고를 때만 열리고, 빈 곳을 누르면 닫힙니다. 종류·크기·위치(폴더를 누르면 그 폴더로)·마지막 수정, **내용이 같은 파일**과 **이름이 같은 파일**(누르면 그 파일로), 그리고 옮기기·이름 바꾸기·휴지통 버튼이 있습니다.

가운데에서 파일을 고르면 왼쪽 폴더 목록이 그 파일이 든 폴더까지 펼쳐지고, 폴더 아래에 고른 파일이 한 줄 나옵니다. 그 줄을 누르면 탐색기가 그 폴더를 열고 파일을 골라 둡니다.

- 파일을 두 번 누르면 열립니다.
- **오른쪽 클릭:** 파일 줄 위에서는 메뉴(열기, 폴더 열기, 예외로 지정), 그 밖의 곳에서는 이전 폴더로 돌아갑니다. 설정 등 다른 화면에서는 목록으로 돌아갑니다.

### 칩 줄

필터 칩, 종류 칩, 확장자 칩은 각각 한 줄입니다. 넘치는 칩은 칩 줄 위에서 마우스 휠을 굴리거나, 눌러서 좌우로 끌어 봅니다. 종류 칩은 많이 누른 것이 왼쪽에 옵니다([전체]는 늘 맨 앞). 누른 횟수는 설정 파일에 남아 다시 켜도 그대로입니다.

### 여러 개 고르기와 끌어 놓기

- **고르기:** 클릭(그 줄만), 체크 칸·Ctrl+클릭(하나씩 더하거나 빼기), 머리글의 체크 칸(모두), Shift+클릭(범위), 고르지 않은 줄이나 표 아래 빈 곳에서 끌기(사각형 안의 줄).
- **옮기기:** 고른 줄을 끌어 왼쪽 폴더 목록의 폴더에 놓습니다. 끄는 동안 커서 옆에 "3개 항목 이동 중"이 보입니다. 왼쪽의 폴더도 끌어서 다른 폴더로 옮길 수 있습니다(색인한 맨 위 폴더는 옮기지 않습니다). 같은 이름이 있으면 덮어쓰지 않고 `이름 (2)`가 됩니다.
- **휴지통:** 고른 줄이나 왼쪽의 폴더를 도구 줄의 휴지통 아이콘에 끌어 놓으면(또는 고른 뒤 아이콘을 누르면) 확인 창이 뜨고, [확인]을 눌러야 휴지통으로 보냅니다.
- 여러 파일을 다루는 동안 아래에 진행률 막대가 나옵니다.

### 조건 검색

검색창 옆의 [조건]을 누르면 파일 안의 글자, 수정한 날짜 기간, 크기 범위(MB)를 더 쓸 수 있습니다. 쓴 조건은 모두 만족해야 합니다.

- 파일 안의 글자를 읽는 형식: txt, md, csv, json, xml, html, log 등의 글자 파일, pdf, docx, xlsx, pptx. 50MB보다 큰 파일은 내용을 읽지 않습니다.
- 글자는 대소문자를 가리지 않습니다.

## 중복 의심·최근 다운로드·최근 수정·안 본 파일

도구 줄의 필터 칩과 설정 화면 맨 위의 숫자 카드 네 개로 봅니다.

- **필터 칩:** 누르면 지금 목록(모든 파일이나 고른 위치)에서 그 파일만 남고, 다시 누르면 풀립니다. 한 번에 하나만 고를 수 있으며 종류 칩, 검색창과 함께 걸립니다. 칩의 숫자도 지금 고른 위치·종류 안에서 셉니다.
- **숫자 카드:** 누르면 모든 파일에서 그 필터 칩이 켜진 목록이 나옵니다.

- **중복 의심:** 내용이 같은 파일입니다. 크기가 같은 파일끼리만 비교하고, 8MB보다 큰 파일은 앞·가운데·뒤 일부만 비교합니다. 그래서 '의심'이니 지우기 전에 확인하세요.
- **최근 다운로드:** 인터넷에서 받은 파일(Windows의 다운로드 표시가 있는 파일)을 받은 시각 순으로 보여 줍니다. 정리해서 옮긴 뒤에도 나옵니다.
- **최근 수정:** 정한 기간 안에 수정한 파일입니다. 기본은 7일입니다.
- **N일 넘게 안 본 파일:** 정한 기간 넘게 열지도 수정하지도 않은 파일입니다. 기본은 90일입니다.

기간은 [설정]에서 바꿉니다. 목록의 파일에는 `중복 의심`, `N일 넘게 안 열었어요` 표시가 붙습니다.

### 예외

예외로 지정한 폴더·파일은 위 네 목록에 나오지 않습니다. 모든 파일과 검색에는 그대로 나옵니다.

- 목록에서 오른쪽 클릭 → [예외로]를 고릅니다.
- [설정]의 예외 목록에서 [빼기]로 되돌립니다.

### 연 시각 기록

Windows가 파일을 연 시각을 기록하지 않도록 설정돼 있으면 [설정]에 안내가 나옵니다. 이때 '안 본 파일'은 수정한 시각으로 판단합니다. 기록을 켜려면 관리자 권한 PowerShell에서 아래를 실행하고 다시 시작합니다.

```bash
fsutil behavior set disablelastaccess 0
```

켜기 전에 연 기록은 알 수 없습니다. Windows는 연 시각을 최대 1시간 늦게 기록할 수 있습니다. 색인이 파일 내용을 읽어도 연 시각은 바뀌지 않습니다.

## 오른쪽 상세의 버튼

- **다른 폴더로 옮기기:** 폴더 고르기 창에서 고른 곳으로 옮깁니다. 여러 개를 골랐으면 모두 옮깁니다. 같은 이름이 있으면 `이름 (2)`가 됩니다.
- **이름 바꾸기:** 하나를 골랐을 때만 됩니다. 같은 폴더에 같은 이름이 있으면 바꾸지 않습니다.
- **휴지통으로 보내기:** 고른 것 모두를 확인한 뒤 휴지통으로 보냅니다.

### 휴지통

이 프로그램은 파일을 영구 삭제하지 않습니다. 지우는 것은 모두 Windows 휴지통으로 가므로 휴지통에서 되살릴 수 있습니다. 휴지통으로 보낼 수 없는 경우(영구 삭제될 수 있는 경우)는 보내지 않고 까닭을 알립니다.

- 고정 디스크가 아닌 곳: 네트워크 폴더, 이동식 디스크(USB 등)
- 휴지통을 쓰지 않도록 설정한 디스크
- 그 디스크 휴지통의 최대 크기보다 큰 파일·폴더

## 오래된 파일 보관

1. **보관할 곳**을 고릅니다(예: `D:\Archive_ColdStorage`).
2. **기간**을 정합니다. 기본은 365일이고, 연 시각과 수정 시각 중 늦은 쪽이 이보다 오래된 파일이 대상입니다.
3. [미리보기]로 종류별 개수와 용량을 보고 [보관 시작]을 누릅니다.

- 실행할 때마다 보관할 곳에 zip 하나(`2026-10-19_1530.zip`)를 만들고, 그 안에 원래 경로(`C/Users/…`)를 살려 넣습니다.
- 압축·동영상·음악·사진처럼 이미 압축된 파일은 다시 압축하지 않고 그대로 넣습니다.
- zip을 다시 열어 모든 파일을 확인(CRC)한 뒤에만 원본을 휴지통으로 보냅니다. 확인이 안 되면 원본은 그대로 두고 만든 zip을 휴지통으로 보냅니다.
- 설치파일(exe 등), 예외로 지정한 곳, 보관할 곳 안의 파일, 휴지통으로 보낼 수 없는 곳의 파일은 넣지 않습니다.
- 끝나면 보관한 개수와 원본 합계, zip 크기를 보여 줍니다. 원본은 휴지통에 있으므로 **휴지통을 비워야 그만큼 공간이 생깁니다.**

## 다운로드 정리하기

1. **정리할 곳**을 고릅니다. 다운로드, 디스크(C:\, D:\ …), 또는 [폴더 고르기]로 고른 폴더입니다.
2. **놓을 곳**을 고릅니다. 이 폴더 안에 `문서`, `발표 자료`, `표`, `PDF`, `사진`, `이미지`, `동영상`, `음악`, `압축`, `설치파일`, `기타` 폴더가 생깁니다. 사진은 jpg·heic와 카메라 원본(raw 등), 이미지는 png·gif·svg 같은 그 밖의 그림(스크린샷 포함)입니다.
3. [미리보기]로 어떤 파일이 어디로 가는지 확인하고 [정리]를 누릅니다.

- 고른 곳 **바로 아래의 파일만** 옮깁니다. 하위 폴더와 그 안의 파일은 그대로 둡니다.
- 받는 중인 파일(`.crdownload`, `.part` 등)과 숨김·시스템 파일은 옮기지 않습니다.
- 같은 이름이 있으면 덮어쓰지 않고 `이름 (2).확장자`로 저장합니다.
- 다른 디스크로 옮길 때는 복사한 뒤 크기를 확인하고 나서 원본을 지웁니다. 다운로드 표시와 만든·수정한 시각은 그대로 남습니다.
- [마지막 정리 되돌리기]로 바로 전의 정리를 원래 자리로 돌립니다. 원래 자리에 같은 이름의 파일이 새로 생겼으면 그 파일은 되돌리지 않고 알려 줍니다.

## 색인

- 놓을 곳은 따로 넣지 않아도 색인합니다.
- Windows, Program Files, AppData, 숨김·시스템 폴더는 색인하지 않습니다.
- 색인은 ① 파일 목록(이름·크기·날짜) ② 중복 확인 ③ 파일 내용 읽기 순서로 합니다. ①이 끝나면 목록과 폴더 나무는 바로 쓸 수 있고, ②·③은 뒤에서 이어집니다. 진행 상황은 왼쪽 아래에 나옵니다.
- 2초마다 저장하므로, 색인 중에 창을 닫거나 [멈추기]를 눌러도 거기까지는 남습니다. 다시 [색인 갱신]을 누르면 아직 하지 않은 파일부터 이어서 합니다. 한 번 읽은 파일은 바뀌지 않는 한 다시 읽지 않습니다.
- 색인하는 동안 [멈추기]를 누르면 지금 읽는 파일까지만 하고 멈춥니다. ①을 끝까지 훑지 못했으면 사라진 파일 지우기는 다음 [색인 갱신] 때 합니다.
- 정리, 되돌리기, 옮기기, 이름 바꾸기, 휴지통으로 보내기는 색인에 바로 반영됩니다. 그 밖에 바뀐 것은 [색인 갱신]을 눌러야 반영됩니다.
- 색인은 `%APPDATA%\file_organizer\index.db`에 있습니다.

## 검사

```bash
.venv\Scripts\python tests.py
```

```bash
.venv\Scripts\python -m pytest
```

pytest는 개발용이라 `requirements.txt`에 없습니다(`pip install pytest`). 둘 다 임시 폴더에 만든 파일로만 확인하며, 실제 설정과 파일은 건드리지 않습니다. 휴지통으로 보내기는 실제 휴지통을 쓰지 않고 확인합니다. 다른 디스크로 옮기는 것까지 확인하려면 `OTHER_DRIVE` 환경 변수에 디스크(예: `D:\`)를 줍니다. 그 디스크에 임시 폴더를 만들었다가 지웁니다.
