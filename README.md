# 파일 정리·검색

다운로드한 파일을 종류별 폴더로 정리하고, 이름·종류·날짜·크기·파일 안의 글자로 찾는 Windows 프로그램입니다. 폴더 구조는 왼쪽의 나무로 보여 줍니다.

## 실행

`dist\file_organizer\file_organizer.exe`를 실행합니다.

소스에서 실행하려면:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python desktop.py
```

exe 만들기:

```bash
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller file_organizer.spec
```

## 정리

1. **정리할 곳**을 고릅니다. 다운로드, 디스크(C:\, D:\ …), 또는 [폴더 고르기]로 고른 폴더입니다.
2. **놓을 곳**을 고릅니다. 이 폴더 안에 `문서`, `이미지`, `동영상`, `음악`, `압축`, `설치파일`, `기타` 폴더가 생깁니다.
3. [미리보기]로 어떤 파일이 어디로 가는지 확인하고 [정리]를 누릅니다.

- 고른 곳 **바로 아래의 파일만** 옮깁니다. 하위 폴더와 그 안의 파일은 그대로 둡니다.
- 받는 중인 파일(`.crdownload`, `.part` 등)과 숨김·시스템 파일은 옮기지 않습니다.
- 같은 이름이 있으면 덮어쓰지 않고 `이름 (2).확장자`로 저장합니다.
- 다른 디스크로 옮길 때는 복사한 뒤 크기를 확인하고 나서 원본을 지웁니다. 다운로드 표시와 만든·고친 시각은 그대로 남습니다.
- [마지막 정리 되돌리기]로 바로 전의 정리를 원래 자리로 돌립니다. 원래 자리에 같은 이름의 파일이 새로 생겼으면 그 파일은 되돌리지 않고 알려 줍니다.

## 색인

검색, 나무, 모아 보기는 색인을 읽습니다. [설정]에서 색인할 폴더를 정하고 [색인 갱신]을 누릅니다.

- 놓을 곳은 따로 넣지 않아도 색인합니다.
- Windows, Program Files, AppData, 숨김·시스템 폴더는 색인하지 않습니다.
- 두 번째부터는 바뀐 파일만 다시 읽습니다.
- 정리하거나 되돌리면 옮긴 파일은 색인에 바로 반영됩니다. 그 밖에 바뀐 것은 [색인 갱신]을 눌러야 반영됩니다.
- 색인은 `%APPDATA%\file_organizer\index.db`에 있습니다.

## 검색

이름, 파일 안의 글자, 고친 날짜 기간, 크기 범위(MB), 종류로 찾습니다. 쓴 조건은 모두 만족해야 합니다.

- 파일 안의 글자를 읽는 형식: txt, md, csv, json, xml, html, log 등의 글자 파일, pdf, docx, xlsx, pptx. 50MB보다 큰 파일은 내용을 읽지 않습니다.
- 글자는 대소문자를 가리지 않습니다.

## 나무

색인한 폴더를 접고 펼치며 봅니다. 폴더 옆의 숫자는 그 아래 전체(하위 폴더 포함)의 파일 수와 용량입니다.

- 검색·모아 보기 결과의 줄을 누르면 나무에서 그 파일 위치까지 펼쳐집니다.
- 파일을 두 번 누르면 열립니다.
- 오른쪽 클릭: 열기, 폴더 열기(탐색기), 나무에서 보기, 예외로.

## 모아 보기

- **최근 받은 파일**: 인터넷에서 받은 파일(Windows의 다운로드 표시가 있는 파일)을 받은 시각 순으로 보여 줍니다. 정리해서 옮긴 뒤에도 나옵니다.
- **최근 고친 파일**: 정한 기간 안에 고친 파일입니다.
- **오래 안 본 파일**: 정한 기간 넘게 열지도 고치지도 않은 파일입니다.

기간은 일 단위로 정하며, 정한 값을 기억합니다.

### 연 시각 기록

Windows가 파일을 연 시각을 기록하지 않도록 설정돼 있으면 화면 위에 안내가 나옵니다. 이때 '오래 안 본 파일'은 고친 시각으로 판단합니다. 기록을 켜려면 관리자 권한 PowerShell에서 아래를 실행하고 다시 시작합니다.

```bash
fsutil behavior set disablelastaccess 0
```

켜기 전에 연 기록은 알 수 없습니다. Windows는 연 시각을 최대 1시간 늦게 기록할 수 있습니다. 색인이 파일 내용을 읽어도 연 시각은 바뀌지 않습니다.

## 예외

예외로 지정한 폴더·파일은 모아 보기 목록에 나오지 않습니다. 정리와 검색에는 그대로 나옵니다.

- 목록이나 나무에서 오른쪽 클릭 → [예외로]를 고릅니다. 폴더를 예외로 하면 그 아래 전부가 빠집니다.
- [설정]의 예외 목록에서 [빼기]로 되돌립니다.

## 검사

```bash
.venv\Scripts\python tests.py
```

임시 폴더에 만든 파일로만 확인하며, 실제 설정과 파일은 건드리지 않습니다. 다른 디스크로 옮기는 것까지 확인하려면 `OTHER_DRIVE` 환경 변수에 디스크(예: `D:\`)를 줍니다. 그 디스크에 임시 폴더를 만들었다가 지웁니다.
