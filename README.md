# 파일 정리

다운로드한 파일을 종류별 폴더로 정리하고, 이름·종류·날짜·크기·파일 안의 글자로 찾는 Windows 프로그램입니다. 중복 의심, 최근 다운로드·수정, 오래 안 본 파일을 모아 보고, 옮기기·이름 바꾸기·휴지통으로 보내기를 할 수 있습니다.

## 실행

`dist\file_organizer\file_organizer.exe`를 실행합니다.

소스에서 실행하려면:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python desktop.py
```

exe 만들기:

```bash
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller file_organizer.spec
```

처음 쓸 때는 [설정]에서 색인할 폴더를 확인하고 [색인 갱신]을 누릅니다. 목록, 검색, 중복 의심 등의 목록은 모두 색인을 읽습니다.

## 화면

- **왼쪽:** 위치(모든 파일, 색인한 폴더), [다운로드 정리하기], [설정].
- **가운데:** 고른 위치나 목록의 파일. 위의 검색창은 파일 이름이나 폴더 이름으로 찾습니다. 종류 칩을 누르면 그 종류만 보이고, 표의 머리글을 누르면 정렬됩니다.
- **오른쪽:** 고른 파일의 종류·크기·위치·마지막 수정과 경로. 경로의 폴더를 누르면 그 폴더 아래의 파일이 가운데에 나옵니다.

파일을 두 번 누르면 열립니다. 오른쪽 클릭하면 열기, 폴더 열기(탐색기), 예외로를 고를 수 있습니다.

### 조건 검색

검색창 옆의 [조건]을 누르면 파일 안의 글자, 수정한 날짜 기간, 크기 범위(MB)를 더 쓸 수 있습니다. 쓴 조건은 모두 만족해야 합니다.

- 파일 안의 글자를 읽는 형식: txt, md, csv, json, xml, html, log 등의 글자 파일, pdf, docx, xlsx, pptx. 50MB보다 큰 파일은 내용을 읽지 않습니다.
- 글자는 대소문자를 가리지 않습니다.

## 중복 의심·최근 다운로드·최근 수정·안 본 파일

목록의 검색창 아래 필터 칩 줄과 [설정] 화면 맨 위의 카드 네 개로 봅니다.

- **필터 칩:** 누르면 지금 목록(모든 파일이나 고른 위치)에서 그 파일만 남고, 다시 누르면 풀립니다. 한 번에 하나만 고를 수 있으며 종류 칩, 검색창과 함께 걸립니다. 칩의 숫자도 지금 고른 위치·종류 안에서 셉니다.
- **카드:** 누르면 모든 파일에서 그 필터 칩이 켜진 목록이 나옵니다.

- **중복 의심:** 내용이 같은 파일입니다. 크기가 같은 파일끼리만 비교하고, 8MB보다 큰 파일은 앞·가운데·뒤 일부만 비교합니다. 그래서 '의심'이니 지우기 전에 확인하세요.
- **최근 다운로드:** 인터넷에서 받은 파일(Windows의 다운로드 표시가 있는 파일)을 받은 시각 순으로 보여 줍니다. 정리해서 옮긴 뒤에도 나옵니다.
- **최근 수정:** 정한 기간 안에 수정한 파일입니다. 기본은 7일입니다.
- **N일 넘게 안 본 파일:** 정한 기간 넘게 열지도 수정하지도 않은 파일입니다. 기본은 90일입니다.

기간은 [설정]에서 바꿉니다. 목록의 파일에는 `중복 의심`, `N일 넘게 안 열었어요` 표시가 붙습니다.

### 예외

예외로 지정한 폴더·파일은 위 네 목록에 나오지 않습니다. 모든 파일과 검색에는 그대로 나옵니다.

- 목록에서 오른쪽 클릭 → [예외로]를 고릅니다.
- [설정]의 예외 목록에서 [빼기]로 되돌립니다.

### 연 시각 기록

Windows가 파일을 연 시각을 기록하지 않도록 설정돼 있으면 [설정]에 안내가 나옵니다. 이때 '안 본 파일'은 수정한 시각으로 판단합니다. 기록을 켜려면 관리자 권한 PowerShell에서 아래를 실행하고 다시 시작합니다.

```bash
fsutil behavior set disablelastaccess 0
```

켜기 전에 연 기록은 알 수 없습니다. Windows는 연 시각을 최대 1시간 늦게 기록할 수 있습니다. 색인이 파일 내용을 읽어도 연 시각은 바뀌지 않습니다.

## 파일 하나 다루기 (오른쪽 상세)

- **다른 폴더로 옮기기:** 폴더 고르기 창에서 고른 곳으로 옮깁니다. 같은 이름이 있으면 옮기지 않습니다.
- **이름 바꾸기:** 같은 폴더에 같은 이름이 있으면 바꾸지 않습니다.
- **휴지통으로 보내기:** Windows 휴지통으로 보내므로 휴지통에서 되살릴 수 있습니다. 휴지통이 없는 곳(네트워크 폴더 등)이라 영구 삭제가 될 때는 Windows가 먼저 경고합니다.

## 다운로드 정리하기

1. **정리할 곳**을 고릅니다. 다운로드, 디스크(C:\, D:\ …), 또는 [폴더 고르기]로 고른 폴더입니다.
2. **놓을 곳**을 고릅니다. 이 폴더 안에 `문서`, `표`, `PDF`, `이미지`, `동영상`, `음악`, `압축`, `설치파일`, `기타` 폴더가 생깁니다.
3. [미리보기]로 어떤 파일이 어디로 가는지 확인하고 [정리]를 누릅니다.

- 고른 곳 **바로 아래의 파일만** 옮깁니다. 하위 폴더와 그 안의 파일은 그대로 둡니다.
- 받는 중인 파일(`.crdownload`, `.part` 등)과 숨김·시스템 파일은 옮기지 않습니다.
- 같은 이름이 있으면 덮어쓰지 않고 `이름 (2).확장자`로 저장합니다.
- 다른 디스크로 옮길 때는 복사한 뒤 크기를 확인하고 나서 원본을 지웁니다. 다운로드 표시와 만든·수정한 시각은 그대로 남습니다.
- [마지막 정리 되돌리기]로 바로 전의 정리를 원래 자리로 돌립니다. 원래 자리에 같은 이름의 파일이 새로 생겼으면 그 파일은 되돌리지 않고 알려 줍니다.

## 색인

- 놓을 곳은 따로 넣지 않아도 색인합니다.
- Windows, Program Files, AppData, 숨김·시스템 폴더는 색인하지 않습니다.
- 두 번째부터는 바뀐 파일만 다시 읽습니다.
- 색인하는 동안 [멈추기]를 누르면 지금 읽는 파일까지만 하고 멈춥니다. 그때까지 읽은 것은 남지만, 끝까지 훑지 못했으므로 사라진 파일 지우기와 중복 비교는 다음 [색인 갱신] 때 합니다.
- 정리, 되돌리기, 옮기기, 이름 바꾸기, 휴지통으로 보내기는 색인에 바로 반영됩니다. 그 밖에 바뀐 것은 [색인 갱신]을 눌러야 반영됩니다.
- 색인은 `%APPDATA%\file_organizer\index.db`에 있습니다.

## 검사

```bash
.venv\Scripts\python tests.py
```

임시 폴더에 만든 파일로만 확인하며, 실제 설정과 파일은 건드리지 않습니다. 휴지통으로 보내기는 실제 휴지통을 쓰지 않고 확인합니다. 다른 디스크로 옮기는 것까지 확인하려면 `OTHER_DRIVE` 환경 변수에 디스크(예: `D:\`)를 줍니다. 그 디스크에 임시 폴더를 만들었다가 지웁니다.
